What it does

Four things, each shown here on a real screen.

See every computer at a glance

One page shows which computers are online, how healthy they are, and what needs a person. Group them by site and department.

  • A health score for every computer, with the reasons behind it
  • Alerts stay open while a fault exists and close themselves when it is fixed
  • Acknowledge an alert once and it stops asking for you

Know what is wrong, and why

Open any computer to see its status, its parts and the most serious fault first, with the evidence behind it.

  • Findings in plain words: “System drive almost full”, not an error code
  • Cleanup that never touches personal files
  • Repairs run in your maintenance window and are checked afterwards

Know what to repair, upgrade or replace

Viro reads every part, its age and its wear, then shows what each computer can accept. Every recommendation comes with the reasons.

  • Early drive-failure warnings that Windows itself does not show
  • What fits: free memory slots, maximum memory, drive type
  • Repair or replace, set against the price of a new computer

Help people without leaving your desk

Watch or control a screen, open a terminal or browse files, and restart with a visible countdown. The person at the computer is told when a session starts.

  • Wake a computer over the network, where its hardware allows
  • Every session is recorded: who, which computer, and why

How it works

1

Install one file

Download the installer for your organization and run it on each computer. There is nothing to configure.

2

Computers appear on their own

Each one reports its health and its parts. Organize them by site and department.

3

Viro does the routine work

Updates, cleanup and common repairs run in your maintenance window. You review what needs a person.

Built so you can trust what it does.

Software that can change your computers has to earn that trust. This is how Viro is built to.

Security and privacy
  • Signed updatesEvery update to the Viro agent is digitally signed and verified before it installs, and rolled back if the new version does not start.
  • Signed actionsEvery administrative action, such as a repair or a restart, is a signed job that the computer checks before it runs.
  • Announced, recorded sessionsThe person at the computer sees a notice when remote help starts. Sessions are recorded.
  • An audit log of everythingWho did what, on which computer and when, with the previous and the new state.
  • Two-step sign-inOwners, administrators and technicians can be required to use an authenticator app.
